# Tabla de Derivadas

1. $\deriv{}{x} c = 0$
2. $\deriv{}{x} x = 1$
3. $\deriv{}{x} x^n = n \cdot x^{n-1}$
4. $\deriv{}{x} u^n = n \cdot u^{n-1} \deriv{u}{x}$
5. $\deriv{}{x} c \cdot u = c \cdot \deriv{u}{x}$
6. $\deriv{}{x} (u+v) = \deriv{u}{x} + \deriv{v}{x}$
7. $\deriv{}{x} (u \cdot v) = u \deriv{v}{x} + v \deriv{u}{x}$
8. $\deriv{}{x} \left(\frac{u}{v}\right) = \frac{v \cdot u' - u \cdot v'}{v^2}$
9. $\deriv{}{x} a^u = a^u \cdot \ln a \cdot \deriv{u}{x}$
10. $\deriv{}{x} e^u = e^u \cdot \deriv{u}{x}$
11. $\deriv{}{x} u^v = v \cdot u^{v-1} \deriv{u}{x} + u^v \cdot \ln u \deriv{v}{x}$
12. $\deriv{}{x} \log_a u = \frac{\log_a e}{u} \cdot \deriv{u}{x}$
13. $\deriv{}{x} \ln u = \frac{u'}{u}$
14. $\deriv{}{x} \text{Sen } u = \text{Cos } u \deriv{u}{x}$
15. $\deriv{}{x} \text{Cos } u = -\text{Sen } u \deriv{u}{x}$
16. $\deriv{}{x} \text{Tan } u = \text{Sec}^2 u \deriv{u}{x}$
17. $\deriv{}{x} \text{Cot } u = -\text{Csc}^2 u \deriv{u}{x}$
18. $\deriv{}{x} \text{Sec } u = \text{Sec } u \cdot \text{Tan } u \deriv{u}{x}$
19. $\deriv{}{x} \text{Csc } u = -\text{Csc } u \cdot \text{Cot } u \deriv{u}{x}$
20. $\deriv{}{x} \text{Arc sen } u = \frac{u'}{\sqrt{1-u^2}}$
21. $\deriv{}{x} \text{Arc cos } u = \frac{-u'}{\sqrt{1-u^2}}$
22. $\deriv{}{x} \text{Arc tan } u = \frac{u'}{u^2+1}$
23. $\deriv{}{x} \text{Arc cot } u = \frac{-u'}{u^2+1}$
24. $\deriv{}{x} \text{Arc sec } u = \frac{u'}{u\sqrt{u^2-1}}$
25. $\deriv{}{x} \text{Arc csc } u = \frac{-u'}{u\sqrt{u^2-1}}$
