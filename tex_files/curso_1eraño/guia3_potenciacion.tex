\section{\textquestiondown Qué es una Potencia?}
% ============================================================

\subsection{Base, exponente y potencia}

Multiplicar un número por sí mismo varias veces es muy común, así que los matemáticos inventaron una forma corta de escribirlo.

\begin{cuadroteoria}
  \textbf{Definición:} una \textbf{potencia} es una multiplicación repetida. Se escribe $a^n$ y se lee «$a$ elevado a la $n$».
  \[
    a^n = \underbrace{a \times a \times a \times \cdots \times a}_{n \text{ veces}}
  \]
  \begin{itemize}
    \item \textbf{Base} ($a$): el número que se multiplica.
    \item \textbf{Exponente} ($n$): cuántas veces se multiplica.
    \item \textbf{Potencia}: el resultado.
  \end{itemize}
\end{cuadroteoria}

\noindent\textbf{Ejemplos:}
\begin{itemize}[leftmargin=*]
  \item $2^3 = 2 \times 2 \times 2 = 8$ (se lee «dos elevado a la tres» o «dos al cubo»).
  \item $3^2 = 3 \times 3 = 9$ (se lee «tres elevado al cuadrado» o «tres al cuadrado»).
  \item $10^3 = 10 \times 10 \times 10 = 1000$ (mil).
\end{itemize}

\newpage

\begin{cuadroadvertencia}
  \textbf{Exponentes especiales:}
  \begin{itemize}
    \item Cualquier número elevado a la $1$ es él mismo: $a^1 = a$. Ejemplo: $7^1 = 7$.
    \item Cualquier número distinto de cero elevado a la $0$ es $1$: $a^0 = 1$. Ejemplo: $5^0 = 1$. (\textquestiondown Por qué? Porque al dividir $5^1 \div 5^1 = 1$ y también $5^{1-1} = 5^0$... ya lo verás en las propiedades.)
  \end{itemize}
\end{cuadroadvertencia}

\subsection{El signo del resultado}

\begin{cuadroteoria}
  \textbf{Regla del signo de una potencia:}
  \begin{itemize}
    \item Base \textbf{positiva} $\Rightarrow$ resultado siempre \textbf{positivo}. ($3^2 = 9$, $2^3 = 8$.)
    \item Base \textbf{negativa} con exponente \textbf{par} $\Rightarrow$ resultado \textbf{positivo}: $(-2)^2 = 4$.
    \item Base \textbf{negativa} con exponente \textbf{impar} $\Rightarrow$ resultado \textbf{negativo}: $(-2)^3 = -8$.
  \end{itemize}
\end{cuadroteoria}

\begin{cuadroadvertencia}
  \textbf{¡Cuidado con el paréntesis!} No es lo mismo $(-2)^2$ que $-2^2$:
  \begin{itemize}
    \item $(-2)^2 = (-2) \times (-2) = 4$ (el paréntesis incluye el signo).
    \item $-2^2 = -(2 \times 2) = -4$ (solo el $2$ está al cuadrado, el signo menos queda afuera).
  \end{itemize}
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto:} \textquestiondown Cuánto es $(-3)^3$?

Como el exponente es impar, el resultado es negativo: $(-3)^3 = (-3) \times (-3) \times (-3) = 9 \times (-3) = -27$.

\section{Propiedades de las Potencias}
% ============================================================

\subsection{Las cinco propiedades mágicas}

Con estas propiedades puedes \emph{comprimir} y \emph{simplificar} potencias sin calcular todo:

\begin{cuadroteoria}
  \textbf{Propiedades de las potencias (con $a$, $b$ enteros y $m$, $n$ naturales):}
  \begin{enumerate}
    \item \textbf{Producto de potencias de igual base:} $a^m \times a^n = a^{m+n}$. \quad Ejemplo: $2^3 \times 2^4 = 2^{3+4} = 2^7$.
    \item \textbf{Cociente de potencias de igual base:} $a^m \div a^n = a^{m-n}$ (con $a \neq 0$). \quad Ejemplo: $3^5 \div 3^2 = 3^{5-2} = 3^3$.
    \item \textbf{Potencia de una potencia:} $(a^m)^n = a^{m \times n}$. \quad Ejemplo: $(2^3)^2 = 2^{3 \times 2} = 2^6$.
    \item \textbf{Potencia de un producto:} $(a \times b)^n = a^n \times b^n$. \quad Ejemplo: $(2 \times 5)^2 = 2^2 \times 5^2 = 4 \times 25 = 100$.
    \item \textbf{Potencia de un cociente:} $(a \div b)^n = a^n \div b^n$ (con $b \neq 0$). \quad Ejemplo: $(10 \div 5)^3 = 10^3 \div 5^3 = 1000 \div 125 = 8$.
  \end{enumerate}
\end{cuadroteoria}

\noindent\textbf{¿Por qué funciona?} Mira el producto: $2^3 \times 2^2 = (2 \times 2 \times 2) \times (2 \times 2)$. \textquestiondown Cuántos doses hay? ¡$5$! Por eso $2^{3+2}$.

\begin{cuadroadvertencia}
  \textbf{Recordatorio:} la propiedad 1 dice que las bases deben ser \emph{iguales}. No puedes usar $2^3 \times 5^2$ como si fueran iguales: ahí se aplica la propiedad 4 (potencia de un producto) solo si \emph{también} los exponentes son iguales.
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto:} Simplifica $\dfrac{2^5 \times 2^3}{2^4}$.

Arriba: $2^5 \times 2^3 = 2^{5+3} = 2^8$. Luego $2^8 \div 2^4 = 2^{8-4} = 2^4 = 16$.

\subsection{\textquestiondown Por qué $a^0 = 1$? (con $a \neq 0$)}

La propiedad del cociente de potencias de igual base permite \emph{demostrar} por qué todo número distinto de cero elevado a la $0$ da $1$. La idea es dividir una potencia entre sí misma: por un lado el resultado es $1$ (todo número dividido entre sí mismo da $1$) y, por otro, al restar los exponentes aparece justamente el exponente $0$.

\noindent\textbf{Ejemplo 1:}
\[
  \frac{(-3)^6}{(-3)^6} = (-3)^{6-6} = (-3)^0 = 1
\]

\noindent\textbf{Ejemplo 2:}
\[
  \frac{2^2}{2^2} = \frac{4}{4} \;\Rightarrow\; 2^{2-2} = 2^0 = 1
\]

\noindent\textbf{Ejemplo 3:}
\[
  5^0 = \frac{5^2}{5^2} = \frac{25}{25} = 1
\]

\begin{cuadroadvertencia}
  \textbf{Conclusión:} $a^0 = 1$ para todo $a \neq 0$. La condición $a \neq 0$ es indispensable, porque no se puede dividir entre $0$ (la expresión $0^0$ no está definida).
\end{cuadroadvertencia}

\section{Potencias con Letras (Mini Álgebra)}
% ============================================================

\subsection{La base puede ser una letra}

En matemáticas usamos \textbf{letras} para representar números que no conocemos (o que pueden cambiar). Una letra se comporta exactamente como un número.

\begin{cuadroteoria}
  \textbf{Definición:} si $a$ es un número cualquiera, entonces
  \[
    a^3 = a \times a \times a, \qquad a^2 = a \times a, \qquad a^1 = a, \qquad a^0 = 1 \ (a \neq 0).
  \]
  Para \textbf{calcular su valor} solo hay que reemplazar la letra por el número que nos digan.
\end{cuadroteoria}

\noindent\textbf{Ejemplo resuelto 1:} Calcula $a^3$ si $a = 2$.

\[
  a^3 = 2^3 = 2 \times 2 \times 2 = 8
\]

\noindent\textbf{Ejemplo resuelto 2:} Calcula $3a^2$ si $a = 2$.

\textquestiondown Ojo! Primero la potencia, después la multiplicación: $3a^2 = 3 \times a^2 = 3 \times 2^2 = 3 \times 4 = 12$. (Si lo hubiéramos hecho mal, $3 \times 2 = 6$ y $6^2 = 36$... \textquestiondown muy diferente, verdad? Por eso el orden importa.)

\begin{cuadroadvertencia}
  \textbf{No confundir:}
  \begin{itemize}
    \item $2a$ significa $2 \times a$ (multiplicar por $2$).
    \item $a^2$ significa $a \times a$ (multiplicar la letra por sí misma).
    \item $2a \neq a^2$ en general. Ejemplo con $a = 5$: $2a = 10$ pero $a^2 = 25$.
  \end{itemize}
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto 3:} \textquestiondown Cuál es el área de un cuadrado de lado $x$? El área es $x^2$. Si $x = 7$ cm, el área es $7^2 = 49$ cm$^2$.

% ============================================================
\subsection{Productos y potencias con letras}
% ============================================================

Las propiedades de las potencias que aprendiste en la sección anterior funcionan \emph{igual} cuando la base es una letra. La letra ocupa el lugar de la base y los exponentes siguen siendo números.

\begin{cuadroteoria}
  \textbf{Reglas de oro (con $a \neq 0$):}
  \begin{itemize}
    \item \textbf{Producto de igual base:} $a^m \cdot a^n = a^{m+n}$. Los exponentes se \emph{suman}.
          \quad Ejemplo: $a^6 \cdot a^3 = a^{6+3} = a^9$.
    \item \textbf{Potencia de una potencia:} $(a^m)^n = a^{m \times n}$. Los exponentes se \emph{multiplican}.
          \quad Ejemplo: $(p^5)^6 = p^{5 \times 6} = p^{30}$.
  \end{itemize}
\end{cuadroteoria}

\begin{cuadroadvertencia}
  \textbf{Ojo con el orden de las operaciones:} primero se resuelven las potencias y \emph{después} los productos.
  \begin{itemize}
    \item $(2x)^3 = 2^3 \cdot x^3 = 8x^3$ (el $3$ se aplica a \emph{todo}: al $2$ y a la $x$).
    \item $3x^0 = 3 \cdot 1 = 3$ (cualquier número elevado a la $0$ es $1$, y queda el $3$).
    \item $(-2p^3)^2 = (-2)^2 \cdot (p^3)^2 = 4 \cdot p^{3 \times 2} = 4p^6$ (exponente par $\Rightarrow$ positivo).
  \end{itemize}
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto 4:} Simplifica $(3mn^2)^4$.

Aplicamos la potencia a cada factor: $3^4 \cdot m^4 \cdot (n^2)^4 = 81 \cdot m^4 \cdot n^{2 \times 4} = 81m^4n^8$.

\noindent\textbf{Ejemplo resuelto 5:} Simplifica $\big[(3x)^2 \cdot (2x^3)^2\big]^3$.

Primero cada paréntesis: $(3x)^2 = 9x^2$ y $(2x^3)^2 = 4x^{3 \times 2} = 4x^6$. Luego $(9x^2) \cdot (4x^6) = 36x^8$, y al cubo: $(36x^8)^3 = 36^3 x^{8 \times 3} = 46656\, x^{24}$.

% ============================================================
\subsection{Exponentes negativos con letras}
% ============================================================

Un exponente negativo es la forma elegante de escribir una \emph{fracción}. Significa «uno dividido entre la potencia»:

\begin{cuadroteoria}
  \textbf{Definición:} si $a \neq 0$, entonces
  \[
    a^{-n} = \frac{1}{a^n} \qquad \text{y en general} \qquad a^{-n} \neq \text{un número negativo}.
  \]
  Un exponente negativo \textbf{invierte la base} (la pasa al denominador) y luego se potencia. Ejemplos:
  \begin{itemize}
    \item $a^{-5} = \dfrac{1}{a^5}$.
    \item $a^{-5} \cdot a = a^{-5+1} = a^{-4} = \dfrac{1}{a^4}$.
  \end{itemize}
\end{cuadroteoria}

\begin{cuadroadvertencia}
  \textbf{No confundir exponente negativo con base negativa:}
  \begin{itemize}
    \item $(-2)^2 = 4$ (base negativa, exponente par).
    \item $2^{-2} = \dfrac{1}{2^2} = \dfrac{1}{4}$ (base positiva, exponente negativo \textrightarrow recíproco).
    \item $(b^{-2})^{-8} = b^{(-2) \times (-8)} = b^{16}$ (negativo por negativo da positivo).
  \end{itemize}
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto 6:} Simplifica $\left(\dfrac{b^{-2}}{b^{-3}}\right)^{2}$.

Cociente de igual base: los exponentes se restan: $b^{-2 - (-3)} = b^{-2+3} = b^1 = b$. Luego $(b)^2 = b^2$.

% ============================================================
\subsection{Potencia de un cociente con letras}
% ============================================================

Cuando una fracción completa se eleva a una potencia, el exponente se aplica tanto al numerador como al denominador:

\begin{cuadroteoria}
  \textbf{Potencia de un cociente:} si $b \neq 0$, entonces
  \[
    \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}
  \]
  Y usando la regla del cociente de igual base: $\dfrac{a^m}{a^n} = a^{m-n}$. Ejemplos:
  \begin{itemize}
    \item $\left(\dfrac{a^{6}}{a^2}\right)^3 = \dfrac{a^{6 \times 3}}{a^{2 \times 3}} = \dfrac{a^{18}}{a^6} = a^{12}$.
    \item $\dfrac{y^2 \cdot (3y^2)^2}{9y^4}$: arriba $(3y^2)^2 = 9y^4$, así que $\dfrac{y^2 \cdot 9y^4}{9y^4} = y^2$ (¡se simplifica todo!).
  \end{itemize}
\end{cuadroteoria}

\begin{cuadroadvertencia}
  \textbf{Cuidado con el orden al simplificar un cociente:}
  \[
    \left(\frac{a^{6}}{a^2}\right)^3 = a^{(6-2) \cdot 3} = a^{12}
  \]
  Primero se simplifica la fracción (restamos exponentes) y \emph{después} se aplica la potencia. No multipliques $6 \times 3$ antes de restar $2$.
\end{cuadroadvertencia}

\subsection{Cambio de base}
% ============================================================

A veces los números son potencias \emph{escondidas} de una misma base. Para simplificar, conviene \textbf{escribirlos todos en la misma base}:

\begin{cuadroteoria}
  \textbf{Potencias clave para reconocer de memoria:}
  \begin{center}
    \begin{tabular}{ll}
      \toprule
      \textbf{Base} & \textbf{Potencias} \\
      \midrule
      Base $2$ & $4 = 2^2$, \quad $8 = 2^3$, \quad $16 = 2^4$, \quad $32 = 2^5$, \quad $64 = 2^6$, \quad $128 = 2^7$ \\
      Base $3$ & $9 = 3^2$, \quad $27 = 3^3$, \quad $81 = 3^4$ \\
      \bottomrule
    \end{tabular}
  \end{center}
  \textbf{Pasos:} (1) escribe cada base como potencia de la base común, (2) aplica potencia de una potencia, (3) usa las reglas del producto/cociente.
\end{cuadroteoria}

\begin{cuadroadvertencia}
  \textbf{Nota:} esto es \emph{cambio de base} para \emph{simplificar potencias}, no el cambio de base de los \emph{logaritmos} (que verás más adelante). Aquí solo reescribimos $64$ como $2^6$, $128$ como $2^7$, $27$ como $3^3$ y $9$ como $3^2$.
\end{cuadroadvertencia}

\noindent\textbf{Ejemplo resuelto 7:} Simplifica $(27^2 \cdot 9^3)^6$.

Escribimos todo en base $3$: $27 = 3^3$ y $9 = 3^2$. Entonces $27^2 = (3^3)^2 = 3^6$ y $9^3 = (3^2)^3 = 3^6$. El producto: $3^6 \cdot 3^6 = 3^{12}$. Y al elevarlo a $6$: $(3^{12})^6 = 3^{12 \times 6} = 3^{72}$.

% ============================================================

  \small

\subsection{Concepto, elementos y casos especiales}

\preguntateo{\textquestiondown Qué es una potencia y qué operación matemática resume?}{%
  Una \textbf{potencia} es una forma abreviada de escribir una \textbf{multiplicación repetida} de un mismo factor. Si $a$ es un número entero y $n$ es un número natural mayor o igual que $1$, se define como:
  \[
    a^n = \underbrace{a \cdot a \cdot a \cdots a}_{n \text{ veces}}
  \]
  Sirve para compactar multiplicaciones largas y describir crecimientos muy rápidos (como doblar una hoja de papel varias veces o el aumento de bacterias que se duplican cada hora). \textbf{Ojo:} nunca debe confundirse una potencia con una multiplicación normal: $2^3 = 2 \cdot 2 \cdot 2 = 8$, jamás $2 \cdot 3 = 6$.
}

\preguntateo{\textquestiondown Cuáles son las partes de una potencia, cómo se leen y qué representan el cuadrado y el cubo?}{%
  En la expresión $a^n$ distinguimos tres elementos:
  \begin{itemize}[leftmargin=*, itemsep=2pt, topsep=2pt]
    \item \textbf{Base ($a$):} el número (o letra) que se multiplica por sí mismo.
    \item \textbf{Exponente ($n$):} indica cuántas veces aparece la base como factor.
    \item \textbf{Potencia:} el resultado de la operación (por ejemplo, en $3^2 = 9$, la potencia es $9$, aunque cotidianamente también se llama «potencia» a toda la expresión $3^2$).
  \end{itemize}
  Se lee «$a$ elevado a la $n$». Dos exponentes reciben nombres especiales por su relación con la geometría: el exponente $2$ se lee \textbf{«al cuadrado»} (área de un cuadrado de lado $l$: $l^2$) y el exponente $3$ se lee \textbf{«al cubo»} (volumen de un cubo de arista $l$: $l^3$).
}

\preguntateo{\textquestiondown Qué ocurre cuando el exponente es $1$? \textquestiondown Qué exponente tiene un número o una letra que aparece «sin exponente»?}{%
  Todo número elevado a la $1$ es igual a sí mismo: $a^1 = a$, porque la base aparece una sola vez como factor (ejemplos: $7^1 = 7$ y $(-5)^1 = -5$). Cuando un número o una letra aparece escrito sin exponente visible (como $2$, $5$ o $x$), su exponente implícito es siempre $1$: $2 = 2^1$ y $x = x^1$. Recordarlo es indispensable para no perder factores al sumar exponentes: $x^4 \cdot x = x^4 \cdot x^1 = x^{4+1} = x^5$.
}

\preguntateo{\textquestiondown Por qué todo número distinto de cero elevado a la $0$ es igual a $1$ ($a^0 = 1$)?}{%
  Porque se deduce directamente de la propiedad del \textbf{cociente de potencias de igual base}. Si dividimos una potencia distinta de cero entre sí misma, por ejemplo $\dfrac{5^3}{5^3}$: por un lado, todo número distinto de cero dividido entre sí mismo da $1$ ($\frac{125}{125} = 1$); por otro lado, al restar exponentes obtenemos $5^{3-3} = 5^0$. Como ambos resultados provienen de la misma división, concluimos que $a^0 = 1$ para todo $a \neq 0$. Ejemplos: $5^0 = 1$, $(-3)^0 = 1$ y $12^0 = 1$.
}

\preguntateo{\textquestiondown Cuánto vale $0^0$ y por qué es indispensable exigir $a \neq 0$ en la regla $a^0 = 1$?}{%
  La expresión $0^0$ \textbf{no está definida}. La justificación anterior proviene de dividir una potencia entre sí misma ($\frac{a^n}{a^n}$), y en matemáticas \textbf{la división entre cero no existe}. Por esa razón, tanto en $a^0 = 1$ como en el cociente de potencias de igual base es obligatorio exigir que la base sea distinta de cero ($a \neq 0$).
}

\preguntateo{\textquestiondown Cómo se comportan las potencias cuando la base es $0$, $1$ o $-1$?}{%
  Son tres bases especiales que aparecen constantemente en operaciones combinadas:
  \begin{itemize}[leftmargin=*, itemsep=2pt, topsep=2pt]
    \item \textbf{Base $0$:} $0^n = 0$ para todo exponente entero positivo $n \geq 1$ (ejemplo: $0^7 = 0$). No está definida para exponentes negativos ni para $0^0$, porque implicaría dividir entre $0$.
    \item \textbf{Base $1$:} $1^n = 1$ para cualquier exponente entero $n$ (multiplicar o dividir $1$ por sí mismo siempre da $1$).
    \item \textbf{Base $-1$:} alterna únicamente entre $1$ y $-1$ según la paridad del exponente: $(-1)^n = 1$ si $n$ es \textbf{par} (ej.: $(-1)^{100} = 1$), y $(-1)^n = -1$ si $n$ es \textbf{impar} (ej.: $(-1)^{2025} = -1$).
  \end{itemize}
}

\preguntateo{Si sabemos que $n^2 = 49$ en $\Z$, \textquestiondown existe una sola base posible? \textquestiondown Qué cambia si el exponente es impar, como en $n^3 = -27$?}{%
  Cuando el exponente es \textbf{par} y la potencia es positiva, existen \textbf{dos} bases enteras posibles (una positiva y su opuesta negativa): $n^2 = 49$ se cumple tanto para $n = 7$ ($7^2 = 49$) como para $n = -7$ ($(-7)^2 = 49$). Además, ninguna potencia entera con exponente par puede dar un número negativo. En cambio, cuando el exponente es \textbf{impar}, hay una \textbf{única} base entera posible, que conserva el signo del resultado: en $n^3 = -27$, la única solución es $n = -3$.
}

\subsection{Signos, paréntesis y jerarquía de operaciones}

\preguntateo{\textquestiondown Cómo se determina el signo del resultado de una potencia en $\Z$?}{%
  El signo depende del signo de la base y de si el exponente es par o impar:
  \begin{itemize}[leftmargin=*, itemsep=2pt, topsep=2pt]
    \item \textbf{Base positiva:} el resultado es \textbf{siempre positivo} ($2^5 = 32$, $3^4 = 81$).
    \item \textbf{Base negativa y exponente par:} el resultado es \textbf{positivo}, porque los factores negativos se agrupan en parejas y $(-) \cdot (-) = (+)$. Ejemplo: $(-2)^4 = (-2)(-2)(-2)(-2) = 16$.
    \item \textbf{Base negativa y exponente impar:} el resultado es \textbf{negativo}, porque al formar parejas sobra un signo negativo sin pareja. Ejemplo: $(-3)^3 = (-3)(-3)(-3) = -27$.
  \end{itemize}
}

\preguntateo{\textquestiondown Cuál es la diferencia entre $(-a)^n$ y $-a^n$? \textquestiondown Siempre dan resultados distintos?}{%
  En $(-a)^n$, el paréntesis indica que el signo menos \textbf{forma parte de la base} y se repite $n$ veces: $(-2)^4 = (-2)(-2)(-2)(-2) = 16$. En cambio, en $-a^n$ (sin paréntesis), el exponente solo afecta a $a$ y el signo menos queda afuera multiplicando al resultado: $-2^4 = -(2 \cdot 2 \cdot 2 \cdot 2) = -16$. Cuando el exponente es \textbf{par} (y $a \neq 0$), sus resultados son \textbf{opuestos} ($16$ frente a $-16$). Cuando el exponente es \textbf{impar}, ambos valores coinciden numéricamente (ej.: $(-3)^3 = -27$ y $-3^3 = -27$), aunque su estructura sigue siendo diferente. Asimismo, en expresiones como $-(-3)^2$, primero se resuelve la potencia $(-3)^2 = 9$ y al final se aplica el signo exterior: $-9$.
}

\preguntateo{\textquestiondown Por qué $3x^0 = 3$ mientras que $(3x)^0 = 1$ (con $x \neq 0$)?}{%
  Porque un exponente afecta únicamente a la expresión que tiene inmediatamente a su izquierda, salvo que exista un paréntesis. En $3x^0$, el exponente $0$ solo actúa sobre $x$, de modo que $3x^0 = 3 \cdot x^0 = 3 \cdot 1 = 3$. En cambio, en $(3x)^0$, el paréntesis agrupa todo el producto $3x$, así que la base completa queda elevada a la $0$ y da $1$.
}

\preguntateo{\textquestiondown Qué jerarquía de operaciones se debe respetar al resolver expresiones combinadas con potencias?}{%
  No se resuelve simplemente de izquierda a derecha; el orden obligatorio es: (1) operar dentro de los \textbf{signos de agrupación} (paréntesis, corchetes, llaves) de adentro hacia afuera; (2) calcular las \textbf{potencias}; (3) efectuar \textbf{multiplicaciones y divisiones} de izquierda a derecha; (4) realizar \textbf{sumas y restas} de izquierda a derecha. Por ejemplo, en $8 + 6^2 - 6^2 \cdot 2^3$, primero calculamos las potencias ($8 + 36 - 36 \cdot 8$), luego la multiplicación ($8 + 36 - 288$) y por último sumamos y restamos ($-244$).
}

\subsection{Propiedades de las potencias y errores frecuentes}

\preguntateo{\textquestiondown Cómo se multiplican potencias de igual base y por qué funciona esta regla?}{%
  \textbf{Producto de potencias de igual base:} se conserva la base y se \textbf{suman} los exponentes:
  \[
    a^m \cdot a^n = a^{m+n}
  \]
  Funciona porque multiplicar potencias de la misma base equivale a juntar todos los factores iguales en un solo producto: $2^3 \cdot 2^2 = (2 \cdot 2 \cdot 2) \cdot (2 \cdot 2) = 2^{3+2} = 2^5$. La regla se extiende a cualquier cantidad de factores ($x^4 \cdot x^5 \cdot x = x^{4+5+1} = x^{10}$) y también vale con exponentes negativos ($a^{-5} \cdot a = a^{-5+1} = a^{-4}$).
}

\preguntateo{\textquestiondown Cómo se dividen potencias de igual base y qué cuidado hay que tener cuando aparecen exponentes negativos?}{%
  \textbf{Cociente de potencias de igual base:} con $a \neq 0$, se conserva la base y al exponente del numerador (dividendo) se le \textbf{resta} el exponente del denominador (divisor):
  \[
    \frac{a^m}{a^n} = a^m \div a^n = a^{m-n}
  \]
  Ejemplo: $\dfrac{3^5}{3^2} = 3^{5-2} = 3^3 = 27$. Si el denominador tiene exponente negativo, hay que respetar la regla de los signos al restar (restar un negativo equivale a sumar): $\dfrac{b^{-2}}{b^{-3}} = b^{-2 - (-3)} = b^{-2+3} = b^1 = b$.
}

\preguntateo{\textquestiondown Qué es la potencia de una potencia y cómo distinguirla del producto de potencias de igual base?}{%
  \textbf{Potencia de una potencia:} cuando una potencia se eleva a otro exponente, se conserva la base y se \textbf{multiplican} los exponentes:
  \[
    (a^m)^n = a^{m \cdot n}
  \]
  Ejemplo: $(2^3)^2 = 2^3 \cdot 2^3 = 2^{3 \cdot 2} = 2^6 = 64$. Para no confundir ambas reglas: en el \textbf{producto} ($a^m \cdot a^n$) la base aparece repetida separada por un «$\cdot$» y los exponentes se \textbf{suman}; en la \textbf{potencia de potencia} ($(a^m)^n$) hay una sola base con dos exponentes separados por paréntesis y los exponentes se \textbf{multiplican}.
}

\preguntateo{\textquestiondown Cómo funcionan la potencia de un producto y la potencia de un cociente (tanto para desarrollar como para agrupar)?}{%
  Cuando una multiplicación o una división completa se eleva a un exponente, dicho exponente se aplica a cada factor o término:
  \[
    (a \cdot b)^n = a^n \cdot b^n \qquad\qquad \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n} \ \ (b \neq 0)
  \]
  Leídas de izquierda a derecha sirven para expandir: $(2 \cdot 5)^2 = 2^2 \cdot 5^2 = 100$. Leídas \textbf{al revés} (cuando las bases son distintas pero tienen \textbf{el mismo exponente}), permiten juntar las bases y simplificar cálculos grandes al instante: $2^{10} \cdot 5^{10} = (2 \cdot 5)^{10} = 10^{10}$ y $\dfrac{8^2}{2^2} = \left(\dfrac{8}{2}\right)^2 = 4^2 = 16$.
}

\preguntateo{\textquestiondown Se pueden juntar en una sola potencia expresiones con bases distintas y exponentes distintos, como $2^3 \cdot 5^2$ o $9^2 \cdot 4^3$?}{%
  No directamente. Para sumar o restar exponentes se necesitan \textbf{bases iguales}, y para agrupar bases en un paréntesis se necesitan \textbf{exponentes iguales}. Por ejemplo, en $9^2 \cdot 4^3 = (3^2)^2 \cdot (2^2)^3 = 3^4 \cdot 2^6$, las bases primas ($3$ y $2$) son distintas y los exponentes ($4$ y $6$) tampoco coinciden. En ese caso, la expresión queda indicada como producto de potencias de bases primas distintas (o se calcula por separado: $81 \cdot 64 = 5184$).
}

\preguntateo{\textquestiondown La potencia se distribuye sobre una suma o una resta? Es decir, \textquestiondown se cumple que $(a + b)^n = a^n + b^n$?}{%
  \textbf{Rotundamente no.} La potenciación \textbf{nunca} es distributiva respecto a la suma ni respecto a la resta. Basta comprobarlo con un contraejemplo numérico: $(2 + 3)^2 = 5^2 = 25$, mientras que $2^2 + 3^2 = 4 + 9 = 13$ ($25 \neq 13$). Siempre debe resolverse primero la suma o resta dentro del paréntesis y luego aplicar el exponente.
}

\preguntateo{\textquestiondown Es correcto sumar los exponentes cuando las potencias se están sumando, como en $2^2 + 2^3 = 2^5$?}{%
  \textbf{No.} La regla $a^m \cdot a^n = a^{m+n}$ aplica exclusivamente a la \textbf{multiplicación}, nunca a la suma ni a la resta. Si probamos con números vemos el error: $2^2 + 2^3 = 4 + 8 = 12$, pero $2^5 = 32$ ($12 \neq 32$). Cuando las potencias se suman o se restan, se calcula cada una por separado.
}

\subsection{Exponentes negativos y cambio de base}

\preguntateo{\textquestiondown Qué significa un exponente negativo ($a^{-n}$) y por qué se cumple esa regla?}{%
  Para todo $a \neq 0$ y entero positivo $n$, un exponente negativo indica el \textbf{recíproco} (invierte la base pasándola al denominador con exponente positivo):
  \[
    a^{-n} = \frac{1}{a^n}
  \]
  Se justifica con el cociente de igual base y $a^0 = 1$: $\dfrac{1}{a^n} = \dfrac{a^0}{a^n} = a^{0-n} = a^{-n}$. Por ejemplo, $2^{-3} = \dfrac{1}{2^3} = \dfrac{1}{8}$ y $a^{-5} = \dfrac{1}{a^5}$.
}

\preguntateo{\textquestiondown Un exponente negativo hace que el resultado sea un número negativo?}{%
  \textbf{No.} El signo del exponente no indica el signo del resultado, sino \textbf{inversión} (fracción). Por ejemplo, $2^{-2} = \dfrac{1}{2^2} = \dfrac{1}{4}$, que es un número \textbf{positivo}. El resultado solo será negativo si la \textbf{base} es negativa y el exponente (en valor absoluto) es impar, como $(-2)^{-3} = \dfrac{1}{(-2)^3} = -\dfrac{1}{8}$.
}

\preguntateo{\textquestiondown Cómo se simplifican fracciones con exponente negativo, como $\left(\dfrac{a}{b}\right)^{-n}$, o potencias con exponente negativo en el denominador, como $\dfrac{1}{a^{-n}}$?}{%
  Cuando una fracción completa está elevada a un exponente negativo (con $a, b \neq 0$), se \textbf{invierte la fracción} y el exponente se vuelve positivo; del mismo modo, si una potencia con exponente negativo está en el denominador, sube al numerador con exponente positivo:
  \[
    \left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n = \frac{b^n}{a^n} \qquad\qquad \frac{1}{a^{-n}} = a^n
  \]
  Ejemplos: $\left(\dfrac{1}{2}\right)^{-1} = 2^1 = 2$ y $\dfrac{1}{x^{-4}} = x^4$. Además, todas las leyes de las potencias siguen valiendo igual con exponentes negativos: $(b^{-2})^{-8} = b^{(-2)(-8)} = b^{16}$ y $\dfrac{m^4}{m^{-1}} = m^{4 - (-1)} = m^5$.
}

\preguntateo{\textquestiondown En qué consiste el «cambio de base» (descomposición en factores primos) y cuáles son los pasos para aplicarlo?}{%
  Consiste en reescribir números compuestos como potencias de una \textbf{base prima común} (por ejemplo, $4=2^2$, $8=2^3$, $16=2^4$, $32=2^5$, $64=2^6$, $128=2^7$; $9=3^2$, $27=3^3$, $81=3^4$; $25=5^2$, $125=5^3$; $49=7^2$, $343=7^3$) o como producto de primos ($12 = 2^2 \cdot 3$, $50 = 2 \cdot 5^2$). (No es el cambio de base de los logaritmos, sino una reescritura para poder usar las propiedades.) Los pasos son: (1) descomponer cada número en potencias de primos; (2) aplicar potencia de un producto y potencia de una potencia; (3) agrupar factores de igual base en numerador y denominador; (4) restar exponentes. Ejemplo: $\dfrac{4^5 \cdot 8^2}{16^3} = \dfrac{(2^2)^5 \cdot (2^3)^2}{(2^4)^3} = \dfrac{2^{10} \cdot 2^6}{2^{12}} = \dfrac{2^{16}}{2^{12}} = 2^4 = 16$.
}

\subsection{Potencias con letras (mini álgebra)}

\preguntateo{\textquestiondown Cómo se comportan las potencias cuando la base es una letra y en qué se diferencia $2a$ de $a^2$?}{%
  Una letra representa un número cualquiera, así que obedece exactamente las \textbf{mismas propiedades} que los números (en esta guía las letras van en la base y los exponentes son números enteros). Es clave distinguir:
  \begin{itemize}[leftmargin=*, itemsep=2pt, topsep=2pt]
    \item $2a$ significa $2 \cdot a = a + a$ (sumar $a$ dos veces).
    \item $a^2$ significa $a \cdot a$ (multiplicar $a$ por sí misma).
  \end{itemize}
  Por ejemplo, si $a = 5$, entonces $2a = 10$ pero $a^2 = 25$; en general, $2a \neq a^2$.
}

\preguntateo{\textquestiondown Qué precauciones hay que tomar al sustituir (evaluar) letras por números en expresiones con potencias?}{%
  Hay dos cuidados fundamentales: (1) encerrar el número sustituido entre \textbf{paréntesis}, sobre todo si es negativo (si $x = -3$, entonces $x^2 = (-3)^2 = 9$, no $-3^2 = -9$); y (2) respetar la \textbf{jerarquía de operaciones}: en $3a^2$ con $a = 2$, primero se resuelve la potencia ($2^2 = 4$) y luego se multiplica por $3$ ($3 \cdot 4 = 12$, jamás $(3 \cdot 2)^2 = 36$).
}

\preguntateo{\textquestiondown Cómo se simplifica un término con signo, coeficiente y varias letras elevado a una potencia, como $(-2p^3)^2$ o $(3mn^2)^4$?}{%
  Se aplica la \textbf{potencia de un producto}: el exponente exterior se distribuye al \textbf{signo}, al \textbf{coeficiente numérico} y a \textbf{cada letra} (multiplicando sus exponentes por potencia de una potencia):
  \[
    (-2p^3)^2 = (-2)^2 \cdot (p^3)^2 = 4p^6 \qquad\qquad (3mn^2)^4 = 3^4 \cdot m^4 \cdot (n^2)^4 = 81m^4n^8
  \]
  Un error clásico es elevar las letras y olvidar elevar el coeficiente numérico o el signo.
}

\preguntateo{Al simplificar una fracción algebraica elevada a una potencia, \textquestiondown qué estrategia conviene seguir?}{%
  Conviene trabajar \textbf{de adentro hacia afuera}: primero se simplifican los coeficientes y se restan los exponentes de las letras iguales dentro del paréntesis, y \textbf{después} se aplica el exponente exterior. Esto mantiene los exponentes pequeños y evita errores:
  \[
    \left(\frac{a^6}{a^2}\right)^3 = \left(a^{6-2}\right)^3 = \left(a^4\right)^3 = a^{12}
  \]
  Si al final queda algún exponente negativo y se pide la respuesta \textbf{sin exponentes negativos}, se traslada esa potencia al otro lado de la fracción cambiando el signo del exponente: $\left(\dfrac{p^3q^2}{pq^5}\right)^{-2} = \left(p^2q^{-3}\right)^{-2} = p^{-4}q^6 = \dfrac{q^6}{p^4}$.
}

  \small
  \textbf{Resumen maestro de potenciación (con $a, b \neq 0$ y $m, n \in \Z$):}
  \begin{center}
    \footnotesize
    \renewcommand{\arraystretch}{1.75}
    \begin{tabular}{@{}ll@{\hspace{14pt}}ll@{}}
      \toprule
      \textbf{Regla / Propiedad} & \textbf{Expresión} & \textbf{Regla / Propiedad} & \textbf{Expresión} \\
      \midrule
      Exponente uno & $a^1 = a$ & Potencia de una potencia & $(a^m)^n = a^{m \cdot n}$ \\
      Exponente cero & $a^0 = 1$ & Potencia de un producto & $(a \cdot b)^n = a^n \cdot b^n$ \\[2pt]
      Exponente negativo & $a^{-n} = \dfrac{1}{a^n}$ & Potencia de un cociente & $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ \\[4pt]

      \bottomrule
    \end{tabular}
    \\[8pt]
    \textbf{Trampas prohibidas:}\quad $(a \pm b)^n \neq a^n \pm b^n$ \qquad$\cdot$\qquad $a^m + a^n \neq a^{m+n}$ \qquad$\cdot$\qquad $0^0$ no definido
  \end{center}

  \item $\left[y^2 \cdot (3y^2)^2\right] \div 9y^4 = (y^2 \cdot 9y^4) \div 9y^4 = 9y^6 \div 9y^4 = y^2$
  \item $7^5 \cdot (-8)^3 \cdot 7^4 \cdot (-8)^{18} = 7^9 \cdot (-8)^{21} = -7^9 \cdot 8^{21} = -7^9 \cdot 2^{63}$ (exponente impar $\Rightarrow$ el signo se mantiene negativo).
  \item $(a^3 b^2 c^4)^2 = a^6 b^4 c^8$ y $(b^3)^4 = b^{12}$; dentro del corchete: $a^6 \cdot b^{4+12} \cdot c^8 = a^6 b^{16} c^8$; al cubo: $a^{18} b^{48} c^{24}$.
  \item Arriba: $(m^2)^3 = m^6$, $(n^3 m)^2 = n^6 m^2$ y $(n^3)^6 = n^{18}$, es decir $m^6 \cdot n^6 m^2 \cdot n^{18} = m^8 n^{24}$. Abajo: $(n^2 m^4)^2 = n^4 m^8$. La fracción queda $\dfrac{m^8 n^{24}}{m^8 n^4} = n^{20}$ ($m^8 \div m^8 = m^0 = 1$), y al cubo: $\left(n^{20}\right)^3 = n^{60}$.
  \item $x^4 \cdot x^5 \cdot x = x^{4+5+1} = x^{10}$
  \item $(a^2b^3)^4 = a^{2 \times 4}b^{3 \times 4} = a^8b^{12}$
  \item $(-3x^2y)^2 = (-3)^2 \cdot (x^2)^2 \cdot y^2 = 9x^4y^2$
  \item $(2m^3)^3 = 8m^9$ y $(3m^2)^2 = 9m^4$; luego $8m^9 \cdot 9m^4 = 72m^{13}$
  \item $\dfrac{a^9}{a^9} = a^{9-9} = a^0 = 1$ (con $a \neq 0$)
  \item $\dfrac{x^7y^5}{x^3y^2} = x^{7-3}y^{5-2} = x^4y^3$
  \item $\left(\dfrac{m^8}{m^2}\right)^3 = \left(m^6\right)^3 = m^{18}$
  \item $\dfrac{a^2b^3}{ab} = a^{1}b^{2}$; luego $\left(ab^2\right)^4 = a^4b^8$
  \item $c^{-3} \cdot c^7 = c^{-3+7} = c^{4}$
  \item $\left(d^{-2}\right)^5 = d^{(-2)(5)} = d^{-10} = \dfrac{1}{d^{10}}$
  \item $\dfrac{k^{-4}}{k^{-6}} = k^{-4-(-6)} = k^{2}$
  \item $\dfrac{n^{-2}}{n^{3}} = n^{-2-3} = n^{-5}$; luego $\left(n^{-5}\right)^{-2} = n^{10}$
  \item $(2a^2)^3 = 8a^6$; luego $8a^6 \cdot 3a = 24a^7$, y al cuadrado: $\left(24a^7\right)^2 = 576a^{14}$
  \item Arriba: $(p^2)^3 = p^6$ y $(q^2)^2 = q^4$, es decir $\dfrac{p^6q^4}{p^4q^4} = p^{2}q^{0} = p^2$. Al elevar a $5$: $\left(p^2\right)^5 = p^{10}$.
  \item $(2a^3)^2 = 4a^6$; entonces $\dfrac{4a^6 \cdot a^4}{4a^5} = \dfrac{4a^{10}}{4a^5} = a^5$
  \item Arriba: $(m^2n)^3 = m^6n^3$ y $(mn^2)^2 = m^2n^4$, es decir $m^8n^7$. Luego $\dfrac{m^8n^7}{m^4n^5} = m^4n^2$
  \item $(2x^2y)^3 = 8x^6y^3$; entonces $\dfrac{8x^6y^3}{4x^3y^2} = 2x^3y$
  \item $\dfrac{p^3q^2}{pq^5} = p^2q^{-3}$; al elevar a $-2$: $p^{-4}q^{6} = \dfrac{q^6}{p^4}$
  \item Arriba: $(x^2y^3)^2 = x^4y^6$ y $(x^3y)^3 = x^9y^3$, es decir $x^{13}y^9$. Abajo: $(x^4y^4)^2 = x^8y^8$. Luego $x^5y$
  \item $\dfrac{y^{-3}}{y^{-5}} = y^{-3-(-5)} = y^2$; al elevar a $-2$: $y^{-4} = \dfrac{1}{y^4}$
  \item $(-2x^2y)^3 = -8x^6y^3$ (exponente impar: negativo) y $(-xy^2)^2 = x^2y^4$ (par: positivo); el producto es $-8x^8y^7$
  \item $(2x)^3 = 8x^3$; arriba: $8x^3 \cdot x^2 = 8x^5$; luego $\dfrac{8x^5}{4x^4} = 2x$; al cuadrado: $4x^2$
  \item $(a^2b)^3 = a^6b^3$ y $(ab^2)^2 = a^2b^4$; el producto es $a^8b^7$; al cuadrado: $a^{16}b^{14}$
  \item $(3m^2n^3)^2 = 9m^4n^6$ y $(2mn)^3 = 8m^3n^3$; el producto es $72m^7n^9$; luego $\dfrac{72m^7n^9}{6m^5n^6} = 12m^2n^3$
  \item $(m^3)^{-2} = m^{-6}$; arriba: $m^{-6} \cdot m^{10} = m^4$; luego $\dfrac{m^4}{m^{-1}} = m^{4-(-1)} = m^5$
  \item $\dfrac{2a^{-2}b^3}{4ab^{-1}} = \dfrac{1}{2}a^{-3}b^4$; al cuadrado: $\dfrac{1}{4}a^{-6}b^8 = \dfrac{b^8}{4a^6}$
  \item $\dfrac{(m^2n^3)^2}{(mn^2)^3} = \dfrac{m^4n^6}{m^3n^6} = m^{1}$; al elevar a $-1$: $m^{-1} = \dfrac{1}{m}$
\end{enumerate}
