## 1. El "Salvavidas" de Nuevo Ingreso (Álgebra y Cálculo)
**Público objetivo:** Estudiantes universitarios de primeros semestres.
**Objetivo:** Demostrar que el problema no es el Cálculo, sino las bases de Álgebra.

*   **Portada:**
    *   Logo Mathwizards.
    *   Título: *Los 7 Errores Algebraicos que te Harán Reprobar Cálculo (y cómo corregirlos).*
    *   Autor: Gabriel Astudillo.
*   **Página 1: Introducción (El Diagnóstico)**
    *   Breve reflexión: ¿Por qué un límite o una derivada sale mal? El 90% de las veces es un error de álgebra básica.
    *   Cómo usar esta guía antes de un parcial.
*   **Páginas 2-4: Los 7 Errores (Formato Comparativo)**
    *   *Estructura para cada error:*
        *   **El Error Fatal:** Ejemplo visual de lo que NO se debe hacer (ej. $\sqrt{a^2 + b^2} = a + b$).
        *   **La Justificación Lógica:** Explicación matemática de por qué es un absurdo.
        *   **La Resolución Correcta:** Aplicación correcta de la propiedad.
    *   *Temas sugeridos:* Separación de fracciones, propiedades de potencias, raíces, simplificación de variables que pueden ser cero, y factor común.
*   **Página 5: Llamado a la Acción (CTA)**
    *   Mensaje: "Dominar el álgebra es solo el primer paso. Si necesitas estructura y método para dominar el Cálculo..."
